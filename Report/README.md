# Technical Report

This directory contains the engineering report for the **Resonant Wireless Power Transfer System**.

The report documents the operation and circuit analysis of a short-range inductive power-transfer demonstrator based on a MOSFET full-bridge transmitter and a rectified receiver supplying a DC motor.

## Report Contents

- System architecture and operating principles
- Analog pulse generation using the NE555P
- Digital pulse generation using an Arduino Uno
- IR2104 gate-driver circuits and IRF740 full-bridge inverter
- Resonant tuning and inductive coupling
- Receiver rectifier and DC-motor load
- Schematic-level engineering review and design considerations
- Verification requirements and project limitations
