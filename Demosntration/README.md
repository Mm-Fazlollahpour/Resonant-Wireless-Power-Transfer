# Hardware Demonstration

This directory contains a demonstration video of the **Resonant Wireless Power Transfer System**.

The demonstration illustrates short-range inductive energy transfer from a MOSFET-based transmitting circuit to a receiving coil, with a **DC motor** serving as the load.
